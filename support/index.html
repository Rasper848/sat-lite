Sat-lite

Support

Sat-lite is an iPhone and Apple Watch app for amateur satellite operation and Icom rig control.

Before you write

  • Pass predictions, the satellite catalog, news and the AR view work without a radio if a Maidenhead grid square is entered in Settings > Station.
  • Tracking, transmit and most digital modes need a supported radio and, to transmit, a valid amateur radio license. Arm TX is required; every transmission has a time limit and unkeys automatically.
  • Network radio passwords, the Winlink password and the QRZ Logbook API key are stored only in the iOS Keychain. Do not include passwords, PINs or API keys in a support message.
